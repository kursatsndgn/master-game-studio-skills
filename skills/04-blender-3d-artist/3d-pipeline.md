# Sub-Agent Domain: @3d-artist

## 1. Autonomous Blender Agent Architecture
`@3d-artist` operates directly inside Blender via headless Python execution or the `PoBruno/mcp-blender-agent` MCP server bridge. It translates high-level art director concepts into production-ready 3D assets.

```text
Prompt / Art Directive --> Python bpy Command Generation --> Headless Blender Execution --> Topology & UV Auto-Unwrap --> PBR Material Assignment --> glTF / FBX Export
```

## 3. Standard Blender Python Modeling Recipe (`bpy`)

Every script generated by `@3d-artist` must follow clean initialization and headless termination standards:

```python
import bpy
import bmesh
import math

# 1. Reset Scene Cleanly
bpy.ops.wm.read_factory_settings(use_empty=True)

# 2. Procedural Geometry Generation
bpy.ops.mesh.primitive_cube_add(size=2.0, location=(0, 0, 1.0))
prop = bpy.context.active_object
prop.name = "Dungeon_Chest_Base"

# 3. Add Bevel Modifier for Stylized Edge Highlights
bevel = prop.modifiers.new(name="Bevel", type='BEVEL')
bevel.width = 0.04
bevel.segments = 2

# 4. Auto UV Unwrap (Smart Project)
bpy.ops.object.mode_set(mode='EDIT')
bpy.ops.mesh.select_all(action='SELECT')
bpy.ops.uv.smart_project(angle_limit=66.0, island_margin=0.02)
bpy.ops.object.mode_set(mode='OBJECT')

# 5. Export to glTF 2.0 (Godot & Unity Native)
bpy.ops.export_scene.gltf(
    filepath="dungeon_chest.gltf",
    export_format='GLTF_SEPARATE',
    export_apply=True
)
```

## 4. Modular Assembly Kitbash Rules
- **Grid Snap Standard:** All modular architectural assets must snap to a strict 2.0m x 2.0m or 4.0m x 4.0m metric grid.
- **Pivot Point Protocol:**
  - Floors: Pivot at center-top `(0, 0, 0)`.
  - Walls: Pivot at bottom-center back edge `(0, 0, 0)`.
  - Props: Pivot at ground base `(0, 0, 0)` for zero-offset terrain placement.
